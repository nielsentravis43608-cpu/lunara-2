# LUNARA V3.0 — Crystal Commerce MVP

## What changed
- 20-question Crystal Energy Test
- Five-energy scoring: Protection / Healing / Love / Wealth / Growth
- Dominant + Secondary energy result
- 20 named energy combinations
- Primary + supporting crystal mapping
- Email / WhatsApp result CTAs
- Existing shop/cart/checkout demo retained
- Shopify deliberately not required for this MVP

## Run
1. Extract the ZIP.
2. Open a terminal in the project folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open `http://localhost:3000`

## Important
The current checkout remains a demo checkout. Connect Shopify/payment only after the test → result → recommendation funnel has been validated.

The test should be positioned as spiritual/self-reflection content, not medical or psychological diagnosis.
